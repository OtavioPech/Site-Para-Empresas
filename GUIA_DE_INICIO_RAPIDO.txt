🚀 GUIA DE INÍCIO RÁPIDO
========================

## PASSO 1: ABRIR O SITE

1. Abra a pasta do projeto
2. Clique duplo em "index.html"
3. Pronto! O site está aberto no navegador

OU use um servidor local:
- No terminal: python -m http.server 8000
- Abra: http://localhost:8000


## PASSO 2: EXPLORAR O SITE COMO CLIENTE

1. Veja a página inicial
2. Clique em "Produtos" para ver a listagem
3. Clique em um produto para ver detalhes
4. Teste a busca e filtros
5. Clique em "Falar via WhatsApp" (não funcionará até configurar)


## PASSO 3: ACESSAR O PAINEL ADMINISTRATIVO

1. Clique em "Admin" no topo
2. Digite a SENHA: admin123
3. Clique em "Acessar Painel"
4. Pronto! Você está no painel administrativo


## PASSO 4: ADICIONAR PRIMEIRO PRODUTO

1. No Dashboard, clique em "➕ Novo Produto"
2. Preencha os campos:
   - Nome do Produto (obrigatório)
   - Descrição (opcional)
   - Preço em R$ (obrigatório)
   - Categoria (clique para criar nova se não tiver)
   - URL da Imagem (opcional)
   - Desconto em % (opcional)
3. Clique em "Salvar Produto"
4. Sucesso! Produto adicionado


## PASSO 5: CRIAR CATEGORIA

1. Clique em "🏷️ Categorias" no menu lateral
2. Clique em "➕ Nova Categoria"
3. Digite o nome (ex: "Eletrônicos")
4. Escolha uma cor
5. Clique em "Salvar Categoria"


## PASSO 6: PERSONALIZAR O SITE

Abra o arquivo "js/config.js" e mude:

```javascript
// Linha 12:
COMPANY_NAME: 'Sua Empresa Aqui',

// Linha 67:
DEFAULT_PHONE: '5511999999999',  // Seu WhatsApp

// Linha 71:
DEFAULT_MESSAGE: 'Olá! Tenho interesse em seus produtos. Podemos conversar?',
```

Também em "css/variables.css":
```css
/* Linha 18-19: Mude as cores */
--cor-primaria: #007BFF;      /* Azul */
--cor-secundaria: #6C757D;    /* Cinza */
```


## PASSO 7: FAZER BACKUP DOS DADOS

1. Vá em Admin > Dashboard
2. Clique em "📥 Exportar Backup"
3. Um arquivo JSON será baixado
4. Guarde esse arquivo em um lugar seguro


## PASSO 8: RESTAURAR DADOS

Se perder os dados:
1. Vá em Admin > Dashboard
2. Clique em "📤 Importar Backup"
3. Selecione o arquivo JSON que salvou
4. Confirme


## ⚠️ IMPORTANTE

### Para o WhatsApp funcionar:
- Abra config.js
- Mude DEFAULT_PHONE para seu número
- Formato: 55 + DDD + número (ex: 5511999999999)
- Teste em um celular (desktop abre WhatsApp Web)

### Senha do Admin:
- Padrão: admin123
- Para mudar: Edite js/config.js, linha 48
- ⚠️ MUDE ISTO EM PRODUÇÃO!


## 📱 TESTAR RESPONSIVIDADE

No navegador:
1. Pressione F12 (abrir developer tools)
2. Clique em "Toggle device toolbar" (ícone de celular/tablet)
3. Escolha diferentes tamanhos
4. Teste a navegação

## ❓ PROBLEMAS COMUNS

**P: O site não abre**
R: Certifique-se de abrir index.html diretamente ou use um servidor local

**P: Produtos não aparecem no painel**
R: Abra o console (F12) e procure por erros

**P: WhatsApp não abre**
R: Número pode estar errado no config.js. Use formato: 55XXXXXXXXXX

**P: Preciso fazer login novamente**
R: Sessão expire após 30 minutos. Basta fazer login novamente
